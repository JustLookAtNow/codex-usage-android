# Codex 余量 · Android（第一阶段）

原生 Kotlin 应用和支持 4×2、4×1、2×1 的桌面小部件，支持 Android 8.0（API 26）及以上。Android 工程独立于 Windows/Python 程序。

## 已实现

- 显示 5h、Weekly 和接口提供的附加额度、套餐、重置时间；顶部额度卡片显示重置点可用数量及到期时间，详情默认折叠。
- 按原始剩余额度变色：15% 以下及等于 15% 为红色，大于 15% 且不超过 40% 为黄色，高于 40% 或未知额度保持原色。应用内百分比和所有尺寸小部件的数字、进度条、圆环同步适配深浅色，额度回升后恢复原色。
- 展开重置点详情可查看标题、说明、状态、类型、发放时间、到期时间和编号；每项右侧的“使用”按钮经确认后使用对应重置点，成功后重新查询额度并更新小部件。超时或结果未知时保留请求编号及所选重置点，手动重试复用同一请求，避免重复消耗。
- Root 默认读取 ChatGPT 安卓应用的当前登录，也支持终端的 Codex 凭据和绝对路径；每次查询重新读取源文件。
- 通过系统文件选择器导入 `auth.json`，支持从电脑复制的文件。只保存查询所需的 access token 和 account ID，使用 Android Keystore / AES-GCM 加密。
- 桌面小部件按实际额度周期及尺寸自动调整排布。有 5h 时保留 5h／Weekly 双周期布局：4×2、4×1 浅色用进度条、深色用双色圆环，2×1 使用带淡色 GPT 水印的 C2 双行布局。仅有 Weekly 时切换单周布局，显示 CODEX 品牌和额度说明；2×1 不显示更新时间或进度图形，4×1、4×2 显示成功更新时间，浅色用进度条、深色用单圆环。点击刷新图标查询，点击主体打开应用。
- 应用页面、额度卡片、按钮和弹窗跟随系统深浅色模式；小部件手动刷新时立即显示“刷新中”，并暂时模糊百分比／圆环，查询结束后恢复清晰，失败时保留旧数据并提示缓存状态。
- WorkManager 每 15 分钟安排后台查询；支持手动刷新，重启后由 WorkManager 恢复调度。系统省电策略可能延迟执行。
- 查询失败保留旧数据并显示错误；遵守接口 `Retry-After`，手动刷新不绕过限流。
- 清除凭据时停止后台任务并删除额度缓存；禁用备份和设备迁移，不记录凭据或原始响应。

## 配置凭据

### Root 自动获取

1. 在手机上的官方 ChatGPT 应用（`com.openai.chatgpt`）中登录账号。
2. 打开应用，点击“Root 自动查找”，在 Magisk / KernelSU 等权限管理器中允许本应用使用 Root。
3. 默认自动选择 ChatGPT 认证文件。若未安装 ChatGPT，则继续查找终端中的 Codex `auth.json`；多个终端文件需要选择。也可通过“Root 自定义路径”指定来源。

自动查找仅检查：

```text
/data/user/0/com.openai.chatgpt/shared_prefs/com.auth0.authentication.storage.xml
/data/data/*/files/home/.codex/auth.json
/data/user/0/*/files/home/.codex/auth.json
/data/data/*/files/.codex/auth.json
/data/local/tmp/.codex/auth.json
```

ChatGPT 来源还会只读检查同目录应用数据下的 `files/datastore/global_session.json`，按当前登录会话选择 `sessions.*.com.auth0.access_token`，从 JWT 的 `https://api.openai.com/auth` 对象中的 `chatgpt_account_id` 字段取得额度账号。不会选择旧的 `users.*` 缓存或其他登录会话。读取前后确认会话索引一致，并检查 XML 和 JWT 中的到期时间。Root 配置只保存路径，不复制 refresh token、ID token 或密钥。

`/data/data/com.openai.chatgpt/` 与 `/data/user/0/com.openai.chatgpt/` 在已验证的手机上是同一数据目录，两种路径均支持。终端来源覆盖 Termux 常见位置 `/data/data/com.termux/files/home/.codex/auth.json`。不递归扫描手机。不同终端和自定义 `CODEX_HOME` 使用自定义路径。

Root 源文件只读，不修改原始登录，也不主动续期。ChatGPT 凭据失效时请打开 ChatGPT 更新登录，之后本应用刷新会重读；终端来源则在相应终端更新登录。自动后台读取需要权限管理器持久允许 Root；授权拒绝或超时会显示错误。认证文件和会话索引属于 ChatGPT 内部格式，后续版本可能变化，解析失败时可使用原有 `auth.json` 方式。

Root 使用 Magisk/KernelSU 的 `su -M -c` 在全局挂载命名空间读取，支持跨应用数据访问；已在 KernelSU 手机验证默认来源和应用内额度刷新。

### 手工导入

点击“手工导入 auth.json”，通过系统文件管理器选择手机上的文件。Windows 上通常来自 `%USERPROFILE%\.codex\auth.json`。不需要 Root 或全盘存储权限，API Key 登录不支持订阅额度查询。

导入模式不会追踪原文件更新，凭据失效后重新导入即可。请妥善处理复制到手机公共存储的原文件；应用只在自己的私有存储中保存加密的必要字段。

## 小部件与网络

点击“添加桌面小部件”，也可长按桌面，从小部件列表选择“Codex 余量”。默认 4×2，长按后拖动边界可缩为 4×1 或 2×1；实际格数由桌面网格和间距决定。所有实例共用一个账号和缓存，自动跟随系统深浅色模式。

从小部件主体打开应用时复用已有首页，避免后台已有首页时再次叠加、需要返回两次才能到桌面。未配置时点击刷新图标也使用同一入口。升级后小部件会更新启动入口，无需清除数据或重新添加。

该入口修复已覆盖安装并在真机检查连续打开及返回行为，用户已人工确认问题解决。

双周期布局的倒计时只显示时长，例如“2小时55分”“6天8小时”，不显示重置日期、“剩余”或“后恢复”小字。单周布局的 2×1／4×1 带“后恢复”说明，4×2 使用独立的“额度恢复”标签。使用本地缓存的恢复时间按当前时间重新计算，按分钟尽力更新，不增加接口请求；采用非唤醒、非精确定时，不申请精确闹钟权限，休眠、省电或系统合并调度时可能延后。额度继续由 WorkManager 每 15 分钟查询，也可手动刷新。恢复时间缺失时不推算时间，倒计时到期显示“0分钟”，不会自行推算额度恢复为 100%。删除最后一个小部件或清除配置时取消倒计时，重启及应用更新后恢复本地调度。

双周期布局及单周 2×1 在正常状态下不显示更新时间；单周 4×1／4×2 显示最近一次成功查询的本地时间（`MM-dd HH:mm`）。本地倒计时更新不会改变成功更新时间，查询失败时保留原时间和缓存布局，并显示简短缓存／失败提示；完整错误及更新时间可点击进入应用查看，也保留于无障碍描述中。

4×1、4×2 深色模式的百分比与圆环一起绘制和缩放，避免在矮小部件内溢出内圈；支持 0%、100% 和未知额度。刷新反馈不额外发起请求，重复点击合并，进程中断时在两分钟有效期后恢复正常显示。

双周期 2×1 的深浅色共用原生双行文字布局，百分比最多 15sp、倒计时最多 9sp，较窄空间自动缩小；64dp GPT 水印居中放在卡片左半部，分别以约 6%／7% 不透明度绘制在底层。透明度直接写入专用矢量图标的路径颜色，避免桌面忽略 ImageView tint 后遮住文字。单周 2×1 改为顶部品牌、下方百分比与额度说明，百分比最多 25sp，并随空间缩小。两种布局均保留刷新入口及短状态提示，刷新期间模糊百分比，正常状态隐藏提示。4×1、4×2 继续使用进度条／圆环布局。

联网采用手机当前网络，包含 VPN。第一阶段不提供应用内 HTTP/SOCKS 代理、网页登录、自动刷新 token、多账号或云端同步。应用只连接 `https://chatgpt.com/backend-api/wham/`，保持 TLS 校验并拒绝重定向。该客户端后端接口可能变化。

## 重置点

刷新后在顶部额度卡片查看重置点数量及按先后排列的到期时间，详细信息默认折叠，点击“展开重置点详情”查看。时间按手机本地时区显示；接口缺少的字段显示“未提供”。明细可能不包含所有点数，可用数量以服务返回的 `available_count` 为准；查询失败时保留上次详情和更新时间并提示可能过时。

展开详情后，点击某个重置点右侧的“使用”，确认后使用该项；可重置的额度周期由服务决定。已使用、过期或缺少有效编号的项目不能使用；发送前重新查询，所选项目不可用时停止。成功消耗后不可撤销；没有可用点数或没有符合条件的额度时会显示对应结果。后台任务只查询，不执行重置。

使用接口为 `POST rate-limit-reset-credits/consume`，请求体包含 `redeem_request_id` 和所选项目的 `credit_id`，实现依据 OpenAI 官方客户端及[官方 App Server 说明](https://learn.chatgpt.com/docs/app-server#8-earned-rate-limit-resets-chatgpt)。请求编号和所选项目在发送前保存；遇到超时、未知结果或限流时，展开详情点击“重试本次重置”复用原请求，重启应用后仍有效。待确认请求绑定账号及所选重置点，确认结果前不允许使用其他项目，来源账号变化时拒绝重试；重新配置或清除凭据会删除待确认状态。成功后从服务重新获取额度，不在本地推算。
